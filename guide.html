FreePDFeditor / A QUICK GUIDE

A good fit. First time.

FreePDFeditor prepares PDFs and images in a single workspace. It runs on your device and uses no AI.

01. Add your documents

Choose PDFs, JPGs, PNGs, HEIC/HEIF, SVG, WebP, GIF, or BMP images. You can select multiple files or a folder. Supported files from the folder are added to a queue; other types are skipped. The current version accepts up to 2,000 files, with a 100 MB limit for each input.

02. Pick the page dimensions

Keep original size, or choose A4, US Letter, A5, or a custom width and height in millimetres. Content is scaled proportionally and centred, without cropping. Images become PDFs. Changing PDF page dimensions creates static pages: interactive form fields and annotations may not carry over, and digital signatures will no longer validate. Keep the original.

03. Set a file-size limit, if needed

Type a maximum size in KB or MB, or leave it blank. KB means 1,000 bytes and MB means 1,000,000 bytes. A limit applies to each output, or to the complete output if you combine the files.

FreePDFeditor first checks whether the PDF fits and tries a structural rewrite. If a size limit cannot be met by rewriting the PDF, stronger compression is attempted automatically. This redraws pages as JPEG images and may remove selectable text, links, form behaviour, accessibility structure, and signature validity. It is best suited to scans and photographs. You can preview the result before downloading.

04. Download the result

Each completed file has Preview and Download controls. Download files saves separate PDFs; enable Download as ZIP for a single archive. Combine into one PDF makes a single document in queue order, including only files processed successfully. If you stop a combined job, its output contains only the completed portion.

Edit and organise a document

Choose Edit or Organize pages, or select Edit beside a file. The editor opens one document at a time. Page thumbnails let you select a page; use Move up, Move down, Rotate, Delete page, or Extract page. Add text, highlights, freehand drawings, or a typed signature. Undo and Redo apply to editor changes. Save PDF downloads the edited document; Export page creates a PNG or JPEG of the current page.

Text tools add new content; they do not replace existing text. Export currently supports Latin characters. Typed signatures are visual marks, not certificate signatures. Rotate before adding marks. Saving creates static pages: form interactivity, original annotations, accessibility structure, and signature validity may not be preserved. Original documents remain unchanged. Page images are exported at up to 150 DPI and capped at 3,000 pixels per side.

What if the target is too small?

FreePDFeditor labels the result “Target not reached” and lets you inspect it. It does not guarantee readable text at every requested size. Consider a larger limit, fewer pages, or a separate file. There is no automatic claim that a PDF is valid for a particular submission portal.

Image formats

All image inputs become PDFs. SVGs are rasterised, not preserved as vectors. SVGs with external or active content are rejected. Animated GIFs and multi-image HEICs use the first image only. Large images may be reduced to fit browser memory. HEIC decoding depends on the codec; unsupported photos receive an error rather than stopping the batch.

Large batches

Files are processed sequentially, with up to 40 rows shown at first. Use Show more files to expand the list. Outputs are held in browser memory up to a 256 MB safety budget. For large collections, download and clear completed batches. Keep the tab open: queue progress is not saved after closing or refreshing it. Password-protected files need an unlocked copy.
