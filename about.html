Less friction.
More getting on.

FreePDFeditor is an early version of a focused PDF workspace, built around a familiar frustration: adjusting a document, checking its size, and starting all over again.

The idea is simple. Set the page dimensions and maximum file size once. Apply them to a queue. See clearly which files worked, which need attention, and what changed.

A small, considered set of tools

Page resizing, JPG and PNG to PDF, combining documents, target-size compression, previews, and ZIP downloads. No account or payment is required in this version.

Built to keep files close

PDF processing happens in the browser using bundled open-source software. Documents are not sent to a processing server. This preview has not been stress-tested on thousands of large files or every PDF format.
